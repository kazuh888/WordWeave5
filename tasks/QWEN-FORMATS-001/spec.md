# QWEN-FORMATS-001 外部仕様差分

2026-10-03。状態：P-F01/P-F02親採用・独立レビュー済み。既存の [本体統合仕様](../QWEN-INTEGRATION-001/spec.md) と [単独仕様](../QWEN-AUDIO-001/spec.md) に対し、音声形式と指定された本体表示だけを変更する。

## 要求・根拠

要求IDは [plan.md](plan.md) のQF-01～07を継承する。利用者要求は6形式を本体・単独GUIの共通libで扱うこと、および本体の3説明削除と取消し注記の変更・移動である。親の制約は既存上限、原音bytes送信、内容検証、動画/複数音声拒否、取消し・旧確認無効化、実API送信なしである。

[Qwen-Omni公式のAudio and text input / Input limits](https://help.aliyun.com/en/model-studio/qwen-omni) を2026-10-03に確認した。音声形式はAMR/WAV/3GP/3GPP/AAC/MP3、Base64は10MB未満と記載される。下表のcodec・コンテナ制約と既存60秒等の制限は、このアプリの互換profileでありAPIの全能力や実接続成功を意味しない。

## 入力互換profile（親採用P-F01）

| 表示/選択形式 | 内容による許容条件 | 送信`input_audio.format` |
| --- | --- | --- |
| WAV | 既存RIFF/WAVE PCM16。float/圧縮WAVは従来どおり拒否 | `wav` |
| MP3 | MPEG Audio Layer III。Layer I/II、frame長を確定できないfree-formatは不可 | `mp3` |
| AAC | ADTS AAC。AACのprofileは使用するdecoderが完全復号できる範囲。M4A/MP4、ADIF、LATM、headerからchannelを確定できないPCE（channel_config=0）は本profile外 | `aac` |
| AMR | AMR-NBまたはAMR-WBの音声ファイル | `amr` |
| 3GP / 3GPP | 3GPPブランドのコンテナで、音声ストリーム一つ、codecはAAC/AMR-NB/AMR-WB。動画・複数音声・外部参照は不可 | 両拡張子とも内容同系のため`3gp`へ統一 |

全形式共通でファイル全体6,291,456 bytes以下、復号後0秒超60秒以下、8,000～48,000Hz、1～2chとする。本体録音は従来の最大30秒である。全復号で検証した音声フレーム数とsample rateで長さを判定し、申告durationだけで合格にしない。encoder padding等で復号長が60秒を超えれば超過扱いであり、無断で末尾を切らない。復号中のsample rate/channel変化、長さ判定不能は拒否する。

実装profile補足：3GPのfragmented（moof）構造は対象外。MP3タグは先頭ID3v2と末尾ID3v1を扱い、その他を推測して読み飛ばさない。AMR-WBはlibopencore_amrwb decoderを備えたFFmpegを必要とする。形式名の全対応は各形式の全codec・全variant対応を意味せず、これらのアプリ制限を利用説明に明示する。

## 一時コピーの限定例外（親採用P-F02）

シークを伴う検査・復号に必要な場合だけ、既に選択・取得したbytesをアプリ専用の一時領域へ短命のコピーとして置ける。原ファイルをbackendが再読して別内容を採用せず、送信時はメモリのsnapshotを使う。通常成功/失敗/取消し/画面終了では自分の一時コピーを削除し、削除失敗時は残留の可能性を通知する。異常終了・OS停止時の完全消去は保証せず、一時音声が残る可能性を利用説明へ記載する。診断へ音声/英文/キーを出さない。

これは旧QA-AC-015/QI-AC-017の入力コピー非保存に対する限定差分であり、録音/結果の保存・履歴機能を許可しない。FFmpeg/ffprobeの利用、探索順、timeout値、出力上限、process停止、一時ファイルの命名/隔離方式は内部設計事項である。既存インストールがこの開発機にあることを配布先の保証にしない。

## 親への確認・引継ぎ

- P-F01のcodec/profileと3GP/3GPPのwire統一、P-F02の一時コピー例外は親採用済みである。公式資料の6形式名だけから全codec対応を推定しない。重大な差があれば利用者へ戻す。
- 本書の完了境界は差分仕様・受入ID・根拠/リンク整合の確認と親への返却まで。ソース/試験・計画・設計は変更しない。後工程は親採用と独立レビュー後に本書へ依存する。
- コマンド、Rust規約、ソース/試験配置は計画と既存仕様を継承し、外部仕様に実装例を追加しない。KPIカウンター・実行model/effortメタデータは本担当では未取得である。

親採用記録：2026-10-03、P-F01のcodec/brand/wire、単独再生UIの新設なし、P-F02のシーク検査用一時コピー例外を親が採用した。独立仕様レビューはP1/P2なし。実装前照合でMP3 free-formatとAAC PCEの明示制限を追加した。これはAPIの制約ではなく、安全な属性・長さ確認のためのアプリ側profileである。
