## 2. 配色（計画U1/U2）

### 2.1 入出力と対象

設定に「配色を調整」を置き、配色専用の移動可能な小ウィンドウを開く。「画面・ダイアログの背景」と「入力欄の背景」の2組に、それぞれ色、濃さ、見本を表示する。操作名は「保存」「キャンセル」「標準色に戻す」とする。「標準色に戻す」は未保存の編集であり、その操作だけでは確定しない。

色は不透明RGBの各成分0–255とし、色選択および `#RRGGBB` の文字入力で再現できる。HEXは大文字小文字を受け付け、表示時は大文字6桁とする。アルファ・透過率入力は設けない。濃さは整数0–100、1刻みとする。混合は各背景の既存明色をB、選択色をC、濃さをdとして、RGB各成分を `round(B × (1 − d/500) + C × d/500)` とした色である。0は元の背景、100は選択色を20%混ぜた最も濃い明色である。「選んだ色そのものとは異なる」ことを短く説明する。色選択と濃さ変更の効果を混同させない。

新規/既存設定とも初期濃さ0、初期選択色は両組 `#000000` とする。濃さ0なら選択色にかかわらず元の背景である。標準色操作はこの2組の初期値へ戻す。入力枠の判別改善は濃さ0にも適用する。旧設定の画面背景 `#F7FAFD` と白いダイアログ等の既存差異を維持し、1つの同色へ塗りつぶすことはしない。

| 対象面 | 背景組の適用 | 入力組の適用/例 |
| --- | --- | --- |
| ホーム | ページの地 | 編集可能欄がある場合 |
| 学習 | ページ・周囲の地 | キーボード解答、文章解答等 |
| 教材 | ページ・編集ダイアログの地 | 検索、教材項目、対象基本語の空欄を含む |
| 語彙を追加 | ページの地 | 語彙入力等 |
| 英語チャット | ページ・ダイアログの地 | メッセージ入力、送信中disabled入力、タイトル変更等 |
| 記録 | ページ・ダイアログの地 | 編集可能欄がある場合 |
| 設定 | ページ・ダイアログの地 | パス、モデル等の文字入力、数値の文字編集部分、配色HEX入力 |
| アプリ内の確認・詳細・編集ウィンドウ | 窓の地 | その中の編集可能な文字入力 |

最後の行には通知詳細、教材レビュー/根拠/差分、教材削除確認、チャット削除/ごみ箱/タイトル、添付確認/添付編集、録音取消確認、バックアップ復元確認、実行記録、バージョン情報、未保存設定確認、倍率/配色editorを含める。設計は実在する画面・ダイアログ一覧へ展開し、上表に対する漏れを確認する。OSが提供するファイル選択等は対象外である。

カードの白地、学習内容の白い紙面、読み取り専用の本文・通知詳細面、ボタン、差分の赤緑、警告/エラー等の意味色、画像原本・教材原本・手書きキャンバス/筆跡は背景配色で変更しない。これらの内部にある編集可能入力欄は入力組の対象である。カードやボタン等の「地」以外へ新しい色を拡張しない。

## 4. 引用診断（計画U4）

### 4.1 利用者向け出力

1件の失敗を次の順で説明する。対応可能な項目だけを事実として示し、欠落情報を他の理由/発言から補完しない。

1. 結果: 「教材案を作成できなかった。教材には登録していない。」等、実際に失敗した段階と非登録を示す。既存案の再検査失敗なら「この案は登録できない」とし、以前に存在する別案を消したと誤解させない。
2. 対象: 例「教材の『説明・使い方』について、AIが返した7番目の変更理由を確認できない」。7はAI応答内の理由の順序であり教材番号/会話番号ではないと説明する。
3. 原因: 例「AIが引用した文が、指定した元の回答にそのまま連続して見つからない」。空白のみ、2000文字超、参照不存在、話者不正等はその検査原因に応じて説明する。
4. 根拠: 例「4組目の質問と回答のうち、Codexの回答」。利用者の質問の場合は「あなたの質問」。1始まり表示である。
5. 比較: 「AIが示した引用」と「作成を依頼した時点の元の発言」を別行/領域で区別して表示する。現在のチャットを編集しても検査対象が変わらないことを明記する。
6. 対処: 元の発言と選択対象を確認し、必要に応じて教材案作成を明示的に再試行する。AIが正確に引用し直す必要があることを示す。利用者へ原文をAIの誤引用に合わせて書き換えるよう求めない。再試行の成功や回数返却は約束しない。

技術情報として「変更理由 7」「path /usage」「往復 4」「role assistant」等の識別値を保持するが、主見出しの代用にしない。既存の「詳細をコピー」は、利用者向けの見出し・比較・対処と技術識別情報を含む表示診断をコピーする。コピーで案の編集や送信は発生しない。

項目名は既存の教材表示に合わせる。`/usage` は「説明・使い方」、`/base` は「基本語」、`/meaning` は「意味」、`/examples/0/note` は「1件目の追加例文の補足」、`/replacements/0/conditions` は「1件目の言い換えの使用条件」とする。他の許可pathも対応する既存教材項目名とし、未知/不正pathは「対象項目を特定できない」とした上で識別値を安全に表示する。存在しない配列添字を実在する項目へ丸めない。
