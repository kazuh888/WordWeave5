# QWEN-INTEGRATION-001 外部仕様

2026-10-03。状態：独立仕様レビューP1/P2なし、親採用済み。実API合格・公開の承認とは別である。
担当の所有は本書のみ。基点は [plan.md](plan.md) のcommitと既存未コミット差分である。

## 目的・要求追跡

英文例文を読む学習者がWordWeave5内で原音と参照英文を確認し、明示的にQwenへ送って日本語の練習助言を得る。
単独ツールと本体が同じ評価ライブラリを利用し、実接続・助言品質を別途確認することがstep2の目的である。
以下は親が伝達した利用者要求・制約の要約であり、利用者発言の直接引用ではない。R-IDは計画書と同一である。

| 要求 | 根拠・内容 |
| --- | --- |
| R1 | step2承認：単独ツールと本体で同じ評価libraryを使い、英文音読から評価へ到達する |
| R2 | 親の安全境界：原音bytes・参照英文・宛先/接続・目的・受取先を固定確認し、GUIの人操作のみで一回送る |
| R3 | 親の初版範囲：英文例文、助言はメモリのみ、学習成績不変更。原音/教材/記録を保持し、Codexチャット/教材生成経路を維持 |
| R4 | 親の認証境界：本体専用資格情報、単独ツールのキーを暗黙移行しない。Tokyoのみ、設定保存でAPIを呼ばない |
| R5 | 親の取消し要件：一回実行、取消し/画面終了後の遅延結果棄却、自動再送なし、遠隔処理・課金は取消保証なし |
| R6 | 計画/既存契約：助言・評価不能・失敗の区別、要求値と返却実値の区別、無効形式拒否、本体30秒録音上限を維持 |
| R7 | step2承認：実Qwen接続と音読助言を確認し、API未接続とmock合格を混同しない |

根拠は [再利用契約](../../docs/reuse/qwen-audio.md)、[単独ツール仕様](../QWEN-AUDIO-001/spec.md)、[利用手順](../../tools/qwen-audio/README.md) である。
同じ英文音読評価の二つの消費者を扱う一能力とし、Framework全面導入、教科共通採点、汎用provider、MCP拡張、成績/結果保存は含めない。

## 未指定部分の具体化案

P-IDは親の採否を要する具体化である。採用記録なしに承認済み要件と扱わず、範囲拡大は親が利用者へ返す。

| 提案 | 観測可能な動作・理由 |
| --- | --- |
| P1 | 教材詳細の主例文から「Qwenで音読評価」を開く専用dialogとする。参照は主例文全文を固定表示し編集しない。教材との対応を明確にし、自由英文編集は初版に加えない |
| P2 | 専用dialogで新しく録音するか、利用者が一件のWAVを明示選択する。チャット等の既存録音を自動選択しない。新規録音は30秒まで、入力WAVは既存60秒/6MiB契約を使う |
| P3 | dialog中だけ入力/結果を保持し、閉じると今回の入力コピー/助言を破棄する。既存原音は削除しない。新規録音は未保存と明示し、保存機能は加えない |
| P4 | 192kHz等の非対応録音は理由と対応形式を表示して送信拒否する。対応WAV選択または対応環境での再録音を案内し、自動変換・切詰めを加えない |
| P5 | dialogは同時一つで、対象教材の切替/編集は閉じるまで阻止する。別経路で対象版が変化した場合は旧確認を無効化し、進行中は取消しと同じ扱いにする |

## 利用者の短い手順

1. 教材詳細の主例文から「Qwenで音読評価」を開き、表示された読む英文を確認する。
2. 初回は本体専用の接続設定へTokyo API HostとAPIキーを入力して保存する。キーを会話へ貼らない。
3. 専用画面で録音を開始/停止するか、手元の対応WAVを一件選択する。音声を確認して評価準備へ進む。
4. 固定された音声情報、参照全文、宛先、目的、受取先、課金の可能性を確認して「評価を送信」を押す。
5. 聞き取った内容と日本語の助言、または評価不能理由を読む。再練習は新しい準備と送信確認を行う。
6. 「取消し」または「閉じる」で終了する。閉じた助言は復元できず、学習成績は変わらない。

## 入出力の形式・上限

この初版は単独ツールの採用済み互換profileを継承する。値はproviderの将来保証を意味せず、拡張には仕様変更を要する。

| 対象 | 条件・形式 |
| --- | --- |
| WAV | RIFF/WAVEのPCM16、1/2ch、8,000～48,000Hz、0秒超60秒以下、全体6,291,456 bytes以下。宣言長、byte rate、block align、data長/フレーム境界、切断/破損を実体検査する。拡張子だけで判定しない |
| 本体新規録音 | 最大30秒。上記評価入力条件も満たす必要がある。無音はローカル形式エラーとせず、評価不能になり得る |
| 参照英文 | 空白だけは不可、10,000 Unicode scalar以下、改行可。英語自動判定なし。命令として実行しない。初版dialogでは教材主例文を編集しない |
| Host | `https://{WorkspaceId}.ap-northeast-1.maas.aliyuncs.com/compatible-mode/v1`。同じHTTPS originまたは末尾slash付きbaseを受け付け正規化。WorkspaceIdは入力値由来の一DNSラベル。userinfo/明示port/query/fragment/別pathは拒否、redirect不追従 |
| 要求値 | model=`qwen3.8-omni-flash`、effort=`medium`固定。`max_tokens=4096`は応答側の指定であり総思考token/課金上限とは表示しない |
| 通信/応答 | 接続10秒、評価180秒、wire応答1MiB、助言JSON65,536 bytes以下。超過/timeoutで失敗し自動再送しない |
| 結果 | UTF-8構造化JSONの `assessment`, `heard_text`, `summary`, `strengths`, `improvements`, `unassessable_reason`。未知fieldを拒否し、自然文を命令として実行しない |

結果の各型・必須/空条件・文字数・配列数・`reference_excerpt`の参照部分文字列条件は [QA仕様の構造化結果](../QWEN-AUDIO-001/spec.md#構造化結果の提案形式p05) と同一である。
`assessed`は聞取英文と助言、`unassessable`は聞取英文null/理由/空の良い点・改善配列である。形式検証は助言の真実性を保証しない。
メモリのみという約束はこの本体の保存動作であり、Alibaba Cloud側の保存/処理/課金の方針を保証しない。

| ケース | 期待・関連AC | 受入証拠 |
