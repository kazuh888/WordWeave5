## ビルド・起動

既に0.1/0.2をビルドできた環境では、同じVisual StudioのC++開発環境とRustを使用できる。新規導入の場合はVisual Studio Installerで「C++によるデスクトップ開発」とWindows SDKを追加し、[Rust公式](https://rust-lang.org/tools/install/)からMSVC版Rustを導入する。

旧版を閉じ、新しいフォルダーで `build.cmd` → `run.cmd` の順に実行する。コマンドの場合は次のとおりである。

```powershell
cargo test --all-targets --locked
cargo build --release --locked --bin wordweave5
.\target\release\wordweave5.exe
```

依存解決済みの `Cargo.lock` を同梱する。初回は依存ライブラリの取得にインターネット接続が必要である。Visual StudioではCargo.tomlのあるフォルダーを開き、ターミナルから実行できる。ビルド失敗時は `build.log` を確認する。

## AI接続

Codex CLIを導入し、PowerShellで `codex login` を実行してChatGPTでログインする。アプリの「設定」→「接続・ChatGPT認証を確認」で確認する。実行ファイルの初期値は `codex`。自動検出できない場合は `codex.exe` を選択する。

アプリはAPIキー認証を拒否し、APIへのフォールバックを行わない。ChatGPT契約の利用枠は消費する。1日の生成試行上限は初期値10回、設定可能範囲0〜1,000回である。利用枠が尽きた場合は処理を停止する。

[公式Codex CLI](https://learn.chatgpt.com/docs/codex/cli) / [公式App Server仕様](https://learn.chatgpt.com/docs/app-server)

## 教材を増やす

| 操作 | 結果 |
| --- | --- |
| 語彙を追加 → NGSLから自動生成・登録 | 同梱の頻度順語彙から言い換え・用法・問題・複数例文を自動登録 |
| 公式NGSLを再取得して自動登録 | 公式CSVを取得後に同じ自動登録を実行 |
| 基本語の入力 / CSV・TXT読み込み | 提供した基本語・熟語から教材を自動登録 |
| 教材 → 英文追加 | 別の場面・用法の例文、日本語訳、解説を追加 |
| 教材 → 日本文を登録して英文を生成 | 原文を保存した後、英文と訳語・構文の解説を保存 |
| 教材 → 言い換えを手動登録 | 語句・意味・使える条件を複数登録 |

初期値は1回5語、1語6例文。例文数は3〜12に変更できる。生成された各語を保存するため、中断・再起動後は「未処理の語から再開」で続けられる。生成済みの自動教材は重複登録しない。AI生成結果は形式検査後に自動保存する。意味や英語の正確さを保証する検査ではなく、教材画面やTSVで確認・編集できる。

内蔵教材は単語120件・熟語8件・構文8件の合計136件である。NGSLの語彙候補は別に同梱する。公式頻度リスト2,809語と補足52語から重複2語を除いた2,859語であり、全語分のAI教材はアプリ実行時に生成する。出典・ライセンス・抽出方法は [data/NGSL-NOTICE.md](data/NGSL-NOTICE.md) を参照する。

## 1日の学習

1. ホームで5分コース、忙しい日は2分コースを始める。
2. 初めての語は意味・用法・例文を確認し、別の問題を挟んで思い出す。
3. キーボード・ペンタブレット・録音で回答する。
4. 回答を照合し、自己評価する。AI認識の誤りは修正してから評価する。
5. 復習時期が近い項目を優先し、復習が多い日は新規を減らす。

初期の練習は「語句・綴り」「使い分け」。設定で「聞き取り」「日本語から英作文」も有効にできる。日本語の問題生成、回答の添削、書き直し、添削履歴の保存に対応する。AIは意味・文法・自然さと対象表現の使用達成を分けて説明し、自己評価を勝手に変更しない。

## 手書き・音声

手書きはWindowsのポインター入力を送るペンタブレットを使用する。筆圧・傾きには依存しない。手書きの自動認識は画像対応のCodexモデルが必要である。

読み上げはWindowsの英語音声を使う。マイクは既定の入力機器を使用し、録音は最大30秒。録音・再生はオフラインで利用できる。自動文字起こしには音声入力に対応したCodex CLIとモデルが必要で、非対応時には送信前に停止する。認識結果は発音採点ではない。

手書きと録音は次の問題に進むと破棄する。録音再生時の一時WAVは通常終了時に削除する。AIを実行した場合、必要な教材・入力文・手書き画像・音声をCodex経由で送信する。このチャットの履歴は自動では引き継がない。

## 保存とバックアップ

保存先は従来どおり `%LOCALAPPDATA%\WordWeave5`。

| ファイル | 内容 |
| --- | --- |
| progress.json | 設定・学習記録・添削履歴・生成試行数・日本文の下書き |
| custom.tsv | 追加・編集した教材。複数の言い換えと例文も含む |
| words.csv | 読み込み済みの語彙候補 |
| generation-queue.json | 未処理の生成対象。成功保存後に1語ずつ除く |
| backups / custom-before-*.tsv | 日ごとの記録・教材バックアップ |
| codex-work | Codexの作業ディレクトリ |

学習記録JSONと教材TSVの両方を書き出せる。候補・未処理キューを含めて別PCへ移す場合は、アプリを終了して保存フォルダー全体をコピーする。Codexのログインは移行先で行う。

旧15列TSVは読み込める。複数の言い換え・例文を含む教材は17列で保存する。[教材形式](data/FORMAT.md)を参照する。追加例文だけの変更では復習成績を維持し、問題・解答・用法などの変更では該当教材を再学習に戻す。

二重起動はファイルロックで防止する。破損データや保存エラーは通知し、元データを既定値で自動上書きしない。バックアップは自動削除しない。
