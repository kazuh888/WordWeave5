# WordWeave 5 — 使い分ける英語

Windows 11向け、Rust製の英語表現学習アプリの初版ソースである。1日5分を初期設定とし、中学・高校水準の基本語から、社外メールで自然な表現、文体の違い、使用条件、例文を学ぶ。

**この配布物は未ビルドのソース一式である。実行ファイルは含まない。作成環境にはRustコンパイラがなく、その追加取得もできなかったため、Rustのコンパイル・テスト実行・Windows実機動作・実API接続は未確認である。** 教材の形式・件数・一意性とCargo.tomlの構文は検査した。確認内容はVALIDATION.mdを参照する。

## 最初に行うこと

1. ZIPを展開する。以下の作業はWindows側で行う。
2. Visual Studio Installerで「C++によるデスクトップ開発」とWindows SDKが入っていることを確認する。既に導入済みなら追加不要。
3. Rustの公式インストーラーで、Windows向けのMSVCツールチェーンを導入する。
4. 新しいターミナルで `cargo --version` と `rustc --version` を実行し、導入を確認する。
5. このフォルダーの `build.cmd` を実行する。テストが成功した後にリリースビルドを行う。初回は依存ライブラリをダウンロードするためインターネット接続が必要である。
6. 成功したら `run.cmd` を実行する。実体は `target\release\wordweave5.exe` である。

ビルドが失敗した場合は `build.log` を確認する。Rustコンパイラ・依存関係・OS連携をこの作成環境で検証できていないため、初回ビルドで修正が必要になる可能性がある。

[MicrosoftのRust環境構築手順](https://learn.microsoft.com/en-us/windows/dev-environment/rust/setup)、[Rust公式インストーラー](https://rust-lang.org/install.html)を参照する。

コマンドで行う場合は、このフォルダーで実行する。

```powershell
cargo test --all-targets
cargo build --release
.\target\release\wordweave5.exe
```

ソースの整形は `cargo fmt --all` で行える。初回の依存解決後に生成されるCargo.lockを保存する。以後の再現ビルドには `cargo build --release --locked` を使う。この配布物には、実際に依存解決したCargo.lockは含めていない。

## 1日の使い方

1. ホームで「5分の学習を始める」を押す。忙しい日は「今日は2分だけ」を選ぶ。
2. 初めての項目は、意味・使える条件・例文を確認する。
3. 別の問題を挟んだ後、答えを隠して思い出す。残りの問題が少ない場合は間隔が短くなるため、学習直後45秒未満の成功は控えめな間隔で復習する。
4. キーボード、ペンタブレット、録音のいずれかで回答する。
5. 「回答を照合」を押し、例と自分の回答を比較する。
6. 「思い出せなかった」「曖昧／ヒントあり」「自力でできた」「すぐ正確にできた」のいずれかを選ぶ。
7. 目標時間になったら、現在の問題を終えて終了する。「ここで終える」で途中終了も可能である。

復習時期が近い項目を優先し、復習候補が6項目を超える日は新規を停止する。新規の1日上限は3項目である。これは5分運用の初期値であり、万人に最適と実証された値ではない。セッションで扱い切れない復習は、元の期限を保持したまま次回へ回す。

初期の出題種類は「語句・綴り」「使い分け」。設定画面で「聞き取り」「自分で作文」を追加できる。1つの教材に4種類の練習を設け、それぞれ別の復習記録を持つ。120項目×4種類で最大480の練習対象となるが、一度に導入しない。

## 手書き・音声

| 機能 | APIキー | 操作 |
| --- | --- | --- |
| ペンタブレットで手書きする | 不要 | 「手書き」タブの白い欄へ書く |
| 手書きと見本を比較して自己評価する | 不要 | 回答後に見本を表示し、自分で照合する |
| 手書き英語を文字として認識する | 必要 | 「手書き英語をAIで文字起こし」を押す |
| 語句・例文の読み上げ | 不要 | 「聞く」ボタンを押す |
| 自分の英語を録音・再生する | 不要 | 「音声」タブで録音し、自分の声を聞く |
| 録音した英語を文字起こしする | 必要 | 「録音をAIで文字起こし」を押す |
| 自作英文や用法の説明についてコメントを得る | 必要 | 照合後に「AIに使い方を確認する」を押す |

ペンタブレットは、Windowsへ通常のポインター入力を送れるものを想定している。メーカーの通常ドライバーを導入する。筆圧・傾き・ペンの消しゴム側・日本語手書きの自動認識には対応していない。マウスで白い欄に線を描くことも可能である。

読み上げにはWindowsの英語音声を使う。利用できない場合はWindowsの言語／音声設定から英語の音声機能を追加し、アプリを再起動する。設定画面で音声と読み上げ速度を選べる。

マイクはWindowsの既定の入力デバイスを使用する。デスクトップアプリのマイクアクセスが許可されている必要がある。録音は最長30秒。録音と手書きは原則メモリ内に保持し、次の問題に進むと破棄する。録音再生時だけ一時WAVを作り、再生終了後に削除する。異常終了時には一時WAVが残る場合がある。

**音声認識は発音採点ではない。** 音声や手書きの認識結果は修正してから使う。機械の読み違いを、自分が覚えていないこととして記録する必要はない。

## 有料AIの設定

設定画面の初期値は次のとおりである。ユーザー自身のAPI契約・利用可能モデルに合わせて変更できる。

| 設定 | 初期値 |
| --- | --- |
| 送信先 | `https://api.openai.com/v1` |
| 添削・手書き認識 | `gpt-4.1-mini` |
| 音声認識 | `whisper-1` |
| 1日のAI送信試行上限 | 10回 |

通常の学習では通信しない。「送信・有料」と表示したボタンを押した処理だけが通信する。初期値で使用する[Responses APIの画像入力](https://developers.openai.com/api/docs/guides/images-vision)と[音声の文字起こしAPI](https://developers.openai.com/api/docs/guides/speech-to-text)の公式仕様を参照して実装している。実際のキーを使った接続試験は未実施である。

APIキーは画面に入力できる。保存を選ばない場合は起動中だけ保持する。「Windows資格情報に保存」を選ぶと、送信先別にWindows資格情報へ保存する。起動時には保存済みキーを読み込む。学習記録・教材・そのバックアップにはAPIキーを保存しない。環境変数 `WORDWEAVE_API_KEY` に設定する方法もある。

添削では現在の教材情報と回答文、手書き認識では手書き欄の画像、音声認識では現在の録音を送信する。自動送信・自動再送・常時録音は行わない。AIのコメントは参考情報として表示し、学習成績を自動変更しない。

上限は「送信試行の回数」であり、金額の上限ではない。失敗したリクエストも回数に含める。利用料金・利用可否はAPI側の契約やモデル設定で確認する。送信先・モデルの設定画面を用意しているが、他社の互換サービスは未検証である。

## 教材の範囲と編集

内蔵教材は120項目・119基本語。ideaにはconceptとvisionを扱う別項目がある。内訳は社外メール59項目、技術説明49項目、表現・読解12項目である。

これは独自に選んだ初期教材であり、日本の中学・高校で学ぶ全単語を網羅したものではない。「中学」「高校」は学習水準の目安であり、特定の教科書や学年への収録を保証しない。学校で既習となる基本語を出発点とし、未知の表現を実用的に学ぶ用途である。

設定で教材をTSVに書き出し、編集・追加した後に取り込める。文字コードはUTF-8、区切りはタブ。15列の仕様はdata/FORMAT.mdに記載した。Excelを使う場合も、最終保存の文字コードに注意する。

取り込み前に追加・変更件数を表示する。同じIDは上書き、新しいIDは追加。既存教材を省略しても削除されない。変更した項目は内容の指紋を比較し、該当項目の復習状態を再学習に戻す。過去の回答ログは残すため、記録画面には改訂前の実績も含まれる。

## 学習記録とバックアップ

保存先は `%LOCALAPPDATA%\WordWeave5`。

- `progress.json`：設定、復習時期、回答履歴、学習時間、AI送信回数。
- `custom.tsv`：追加・編集した教材。取り込み後に作成される。
- `backups`：日ごとの学習記録バックアップ。
- `progress-before-restore-*.json`：復元直前の元記録。
- `custom-before-*.tsv`：教材取り込み前の元教材。

アプリは二重起動による書き込み競合を防ぐ。保存は一時ファイルへの書き込み後に置換する。破損した学習記録を見つけた場合、勝手に初期化せず学習を停止する。設定画面から正常な記録を選んで復元できる。

バックアップは自動で削除しない。不要になったものは、アプリを閉じてからユーザーの判断で整理する。他のPCへ移す際は学習記録JSONと教材TSVの両方を移す。APIキーは別途設定する。

## 開発者向け

画面と学習処理はRustで実装しており、ブラウザーやNode.jsを実行時に要求しない。構成・計算規則・未確認事項はARCHITECTURE.md、RESEARCH.md、VALIDATION.mdに記載した。
