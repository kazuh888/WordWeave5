# 操作制御の追加仕様

2026-09-17。利用者が確認した追加案に基づく。Windows版のみ。

## 機能と依存

| ID | 責務 | 依存 |
| --- | --- | --- |
| diagnostics | 本文・認証情報を含まない永続診断、容量制限、手動出力 | なし |
| effort | サーバーの候補取得、指定値送信、実行値との区別 | diagnostics |
| chat-trash | 会話のごみ箱移動・閲覧・復元、添付解除の名称 | diagnostics |
| recording-controls | 一時停止・再開・未確定録音のキャンセル | diagnostics |
| speech-controls | 5秒前後移動、停止、再開、位置表示、0.5〜4倍 | diagnostics |

統合順は診断→設定→チャット→録音→読み上げ。媒体原本・教材・復習記録を消さない。

## 契約と受入条件

- 診断: ローカルJSONL、日時・処理ID・入口・イベント・エラー分類・所要時間。本文・媒体・ユーザーパス・認証情報を含めない。最大5ファイル各1MiB、30日。診断失敗は本処理の失敗と分ける。実行台帳を診断出力へ混ぜない。
- effort: 空欄はCodexの既定値。モデル別候補はmodel/listから取得。取得不能や非対応を推測で補わない。実行開始時にも検査。WordWeave内だけに保存し共通Codex設定は変更しない。実行表示はサーバー返却値だけ。
- チャット: 通常50件、ごみ箱500件、双方の合計20MB。ごみ箱は自動消去しない。上限は理由を表示して停止する。通常一覧・送信対象から外し、読み取り専用で閲覧し復元可能とする。教材根拠・原本・復習状態を保持。保存成功後だけ画面へ反映する。処理中・未保存媒体編集中・未承認提案の対象は移動不可。
- 添付: 「添付を外す」とし、当該下書きへの添付だけを解除する。文字起こしから反映済みの文章は削除しない。
- 録音: pause中は収録せず時間にも含めない。再開で連結し無音を挿入しない。最大実録音30秒。録音終了は保存、キャンセルは確認後に今回の未確定メモリだけ破棄する。
- 読み上げ: Windows音声合成と操作可能なプレイヤーを分離する。±5秒は境界内、pauseは位置保持、stopは先頭へ戻す。0.5〜4倍は再生中に変更可能。位置・長さ・状態を表示し、失敗を報告する。声質・速度・実デバイス動作は自動テストとは別に実機確認する。

## 実装・検証

既存Rust/eguiの構造を維持し、UIのまとまった操作はsrc/appの子モジュールへ置く。純粋ロジックはモジュール単体テスト、通信は既存mock_codex、保存は隔離した一時フォルダーで検証する。新規フィールドは旧JSONの既定値を設ける。テストを先に追加し失敗を確認してから実装する。

例: `let mut next = self.progress.clone(); /* 検査・変更 */ storage.save(&next)?; self.progress = next;`

- 全テスト: `cargo test --all-targets --locked`
- release: `cargo build --release --locked --bin wordweave5`
- 差分: `git diff --check`
- 実機: マイクpause/resume/cancel、TTSの位置・速度・停止、CLI0.153.4の実生成とeffort表示。

## 実装上の判断

- 読み上げ速度・位置を途中で変更するため、Windows音声合成の出力をWinRT MediaPlayerへ渡す。合成速度の変更だけでは再生位置の移動や途中の速度変更を満たさない。UIスレッドを合成完了待ちで止めず、全画面共通の操作欄から完了をポーリングする。
- 録音時間は壁時計でなく収録サンプル数で計算する。一時停止はサンプルの追加を止め、デバイス障害時は音声と警告を停止後にまとめて取得する。
- ごみ箱は会話の削除日時だけを変更する。保存成功前には画面へ反映せず、復元時も通常会話上限を検査する。添付再保存は選択中の会話ではなく保存対象IDの削除状態を検査する。
- 診断の目的は「どの処理段階で失敗したか」「中断かタイムアウトか」「保存失敗か」「再起動をまたいで何が起きたか」の判別である。秘密情報を漏らし得る任意文字列の追記を避け、型付きの段階・分類・処理IDを使う。媒体原本と、本文を含む実行台帳は自動出力しない。
- 途中で途切れた診断の最終行は原本を切り詰めず、次のファイルに記録する。出力時はEOFによる未完了行だけを除外する。不正な完全行や未知項目は黙って共有せず出力を停止する。

## 保持する境界

ChatGPT認証のapp-serverのみ。APIキーへの切替、CLI差替え、Volta探索の撤去、既存データの完全削除、Android、録音プレイヤー全面改修、前後文移動、保存済み媒体ブラウザーは行わない。必要なWindows APIの公開は最小限とし、既存依存バージョンを更新しない。古い検証記録を新機能の合格証拠にしない。
