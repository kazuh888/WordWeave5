# 既存機能を活かしたUX改善（承認済み仕様）

2026-09-21に承認された実装計画。開始点は0.5.1 / `4a7a662`。

## 目的と境界

約5分の学習を、開始・回答・振り返り・終了または継続まで迷わず操作できるようにする。
Windows / eguiを維持し、依存関係・出題アルゴリズム・永続形式を全面変更しない。
Android、新しい問題形式、能力推定、画像だけに描かれた新規取込形式や汎用添付は対象外。

## 実施順序

1. 現行調査と仕様確定。
2. 学習：問題と回答を主領域にし、IME安全な入力操作、明示的な自己評価、補助説明を整理。
3. ホーム：開始／再開を主操作にし、今日の実績と累計の優先順位を分ける。
4. 終了：今回の実績と「終了／もう少し学習」を表示。時間到達、手動終了、対象なしを区別。
5. 教材・語彙追加：閲覧と管理、追加方法の入口を分ける。
6. チャット：主操作と補助操作、教材化の段階、実際の処理と回復を明示。
7. 記録：日別学習時間・回答・新規／復習を主に表示。
8. 設定：学習・音声・AI・教材保全・診断を区分。
9. 共通UIの統一、回帰試験、実機受入、完了判定。

## 表示とデータの契約

- ホーム開始と学習タブは同じ開始処理を使用。進行中は既存セッションを再開する。
- 時間到達時に入力や録音を破棄しない。回答後の区切りで終了する。
- 語句入力はIME確定を除くEnterで照合。複数行英文はEnter改行／Ctrl+Enter照合。
- 次問へは本人の評価を記録する。未選択EnterをGood扱いにしない。
- 学習済みは1回以上回答した語彙であり、習得済みではない。自己評価と登録解答照合を区別。
- 学習時間には日別study_secondsを使用し、休止等を含むReview.secondsと混同しない。
- 終了集計はメモリ上のスナップショット。新しいセッション保存形式は導入しない。
- 継続しても既存の復習期限、新規日上限、補助あり評価を維持する。
- ChatGPT認証のCodex app-serverのみ。PATH補完とVolta直接起動を維持。
- 要求モデル／effortとサーバー返却値を区別。未取得値や接続成功を推測しない。
- チャット教材化は選択往復→案→差分・根拠確認→明示登録。追加と訂正を区別。
- 教材・記録・録音・筆跡、ごみ箱と復元を保持。実データを開発試験で書き換えない。

## 受入条件

- 学習開始→入力→照合→明示評価→次問→結果→終了／継続が成立する。
- 0回答、対象なし、時間超過、未記録回答、録音、AI待機、保存失敗で状態が正確である。
- 再描画・操作連打で記録を二重登録しない。
- 教材閲覧・生成・更新・取込、チャット・教材化・復元、設定保存が回帰しない。
- 最小820×650と文字倍率80～160%で主操作を利用できる。
- 変更後の `cargo test --all-targets --locked` とreleaseビルドが成功する。
- 実マイク・ペン・TTS・実Codex・保全済み記録の更新確認は自動試験と別に記録する。

進捗・実行結果は検証記録に記載する。本仕様の受入条件を未検証のまま完了扱いにしない。
