# 教材TSVの形式

UTF-8、タブ区切り、1行1項目。旧形式は15列、新形式は17列である。15列と17列の行を混在させて読み込める。Excelなどで編集した場合はUTF-8で保存する。フィールド内に改行やタブを入れない。空値には半角ハイフン `-` を使う。ただし解答・IDなど必須の内容をハイフンで代用しない。

| 列 | 名前 | 内容 |
| --- | --- | --- |
| 1 | id | 一意のID。半角英数字・ハイフン・下線 |
| 2 | base | 基本語 |
| 3 | meaning | 基本語の日本語の意味 |
| 4 | level | 学習水準の目安。中学／高校など |
| 5 | business | 社外メールで使える語・語句。元の語を残してよい |
| 6 | elevated | 正式・文語的・文学的な表現。なければ `-` |
| 7 | register | 語調や意味の違いを表すラベル |
| 8 | usage | 用法、品詞、意味を保てる条件など |
| 9 | context | 例文を使う場面 |
| 10 | example | 空欄 `___` をちょうど1つ含む英文 |
| 11 | translation | 空欄を埋めた英文の和訳 |
| 12 | answers | 空欄の解答。自然な別解は `|` で区切る。先頭を標準例にする |
| 13 | question | 使い分けを説明させる質問 |
| 14 | explanation | 質問への説明例・重要な観点 |
| 15 | tag | 分類。社外メール／技術説明／表現・読解など |

取込上限は64MB・10,000項目。重複ID、空フィールド、列数の誤り、空欄が複数ある例文などは拒否する。1項目の「語句・綴り」「使い分け」「聞き取り」「作文」の成績は別々に記録する。

英語の正規化は、大文字小文字・前後の空白・連続する空白・末尾の句読点の一部・曲がったアポストロフィに限定する。単複、時制、スペルミス、別の意味をAIが勝手に同一視することはない。未登録の別解には「例とは異なる」と表示し、自分で評価できる。

基本語に形だけ似た難語を割り当てない。例えばcontemporaryは単なるnewの正式語ではなく、despiseはhateに軽蔑の意味を加える。難しい語を使わず基本語を維持する判断も教材に含める。


## 0.3の拡張列

| 列 | 名前 | 内容 |
| --- | --- | --- |
| 16 | replacements | JSON配列。各要素はphrase（語句）、meaning（意味）、conditions（置換可能な条件） |
| 17 | examples | JSON配列。各要素はenglish（完成英文）、japanese（日本語訳・原文）、note（語感・使い方の説明） |

拡張列を付ける場合は両方必要で、空の配列は`[]`とする。言い換え最大30件、例文最大200件。各項目の文字列は空にできず、UTF-8で4,000バイト以下とする。JSON内の改行は`\n`でエスケープする。言い換えや例文の重複は大文字小文字・句読点などを正規化して拒否する。

例文と置き換えの配列は学習用の補足データであり、12列目のanswersとは別である。すべての言い換え候補がその空欄問題の正解になるわけではない。追加配列だけを変えても復習成績は初期化しない。
